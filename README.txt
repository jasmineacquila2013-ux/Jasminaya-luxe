JASMINAYA LUXE — WEBSITE COMPANY PROFILE
========================================

ISI FOLDER
- index.html : halaman Home
- about.html : halaman About Us
- style.css  : desain dan responsive layout
- script.js  : menu mobile dan tahun copyright

CARA MENJALANKAN DI VISUAL STUDIO CODE
1. Ekstrak file ZIP ini.
2. Buka VS Code.
3. Pilih File > Open Folder, lalu pilih folder jasminaya-luxe.
4. Pasang ekstensi Live Server (jika belum ada).
5. Klik kanan index.html dan pilih "Open with Live Server".
6. Gunakan navigasi Home dan About Us untuk berpindah halaman.

CATATAN
- Foto dan font menggunakan layanan online, sehingga memerlukan internet.
- Nama koleksi parfum dan email kontak adalah contoh; silakan ganti sesuai kebutuhan.
- Website ini adalah company profile statis, belum memiliki keranjang atau pembayaran online.
